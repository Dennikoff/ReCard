# Recards

iOS-приложение для изучения иностранных слов по карточкам с интервальным повторением.

**Полная спецификация — [SPEC.md](SPEC.md). Читай её перед любой работой над задачей и не противоречь ей.**
Если задача требует отступить от спецификации — сначала скажи об этом и предложи правку SPEC.md, не меняй поведение молча.

## Стек

- SwiftUI, iOS 26.0+, только iPhone, только портрет
- SwiftData для хранения
- Единственная внешняя зависимость: `swift-fsrs` (SPM), закреплена на коммит `main` — у тега `v5.0.0` инициализаторы не `public`
- Swift Testing для юнит-тестов
- Локализация через `Localizable.xcstrings` (ru, en)

## Архитектура

- Никаких архитектурных фреймворков. `@Observable`-классы как вью-модели.
- Логика планирования и проверки ответов живёт в `Services/` и **не импортирует SwiftUI**. Она должна быть тестируемой без UI.
- `swift-fsrs` изолирован за протоколом `Scheduler`. Типы пакета не должны появляться нигде, кроме `FSRSScheduler.swift`.

## Правила, которые легко нарушить по невнимательности

- **Поля ввода ответа** обязаны иметь `.textInputAutocapitalization(.never)` и `.autocorrectionDisabled()`. Иначе система молча ломает проверку.
- **Навигационные бары не скрывать.** `.toolbar(.hidden)` и кастомные хедеры отключают интерактивный свайп назад — это явное требование продукта.
- **Результат ответа пишется в базу сразу**, после каждой карточки. Понятия «незавершённая сессия» не существует.
- **`ReLog` пишется всегда**, даже несмотря на то, что в v1 он нигде не читается.
- **Имена `Card`, `CardState`, `Rating`, `ReviewLog` заняты пакетом FSRS.** Модели приложения называются `ReCard`, `ReCardState`, `ReRating`, `ReLog` — не переименовывать обратно.
- **Чистая логика помечается `nonisolated`.** Проект собран с `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`, и без явной пометки сервисы нельзя вызвать вне главного актора. Это касается и расширений: они не наследуют `nonisolated` от типа.
- **Модели SwiftData остаются CloudKit-совместимыми**: все свойства опциональны или имеют значение по умолчанию, `@Attribute(.unique)` не использовать.
- **Языки колоды неизменяемы** после создания.
- **Артикль — часть строки слова.** Отдельной логики родов и артиклей не существует.
- **Список языков строится на рантайме** из `AVSpeechSynthesisVoice.speechVoices()`, а не хардкодится.

## Тесты

Обязательно покрываются `AnswerChecker` (нормализация, диакритика, расстояние, синонимы), `FSRSScheduler` (маппинг оценок, критерий архивации) и `SessionBuilder` (блоки, разнесение парных карточек). UI-тесты не пишем.

Запуск:

```bash
xcodebuild test -scheme recards -destination 'platform=iOS Simulator,name=iPhone 17'
```

Схема `recards` генерируется Xcode автоматически и включает цель `recardsTests`. Общей схемы в `xcshareddata` нет намеренно: две схемы с одинаковым именем ломают `xcodebuild`.
