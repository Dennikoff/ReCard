Проект `recards` — iOS-приложение для изучения слов с интервальным повторением. Сейчас в репозитории только пустой SwiftUI-шаблон (`recardsApp.swift`, `ContentView.swift`), кода ещё нет.

Полная спецификация лежит в `SPEC.md`, правила работы над проектом — в `CLAUDE.md`. **Прочитай оба файла целиком, прежде чем что-либо делать.** Спецификация подробная и является результатом длинного проектного обсуждения: все решения в ней приняты осознанно, включая те, что перечислены в разделе 16 как отвергнутые. Не переизобретай их.

Реализуй **этап 1 «Фундамент»** из раздела 15 спецификации:

1. Настрой Xcode-проект: `PRODUCT_BUNDLE_IDENTIFIER = com.kharke.recards`, `TARGETED_DEVICE_FAMILY = 1` (только iPhone), только портретная ориентация, `CFBundleDisplayName = Recards`, `IPHONEOS_DEPLOYMENT_TARGET = 26.0`.
2. Подключи `swift-fsrs` через SPM: `https://github.com/open-spaced-repetition/swift-fsrs`. Проверь актуальную версию и API пакета по его README — сигнатуры менялись между мажорными версиями, не полагайся на память.
3. Создай модели SwiftData `Deck`, `Word`, `Card`, `ReviewLog` строго по разделу 2 спецификации, в отдельных файлах в `Models/`. Все свойства опциональны или с дефолтами, `@Attribute(.unique)` не использовать.
4. Настрой `ModelContainer` в `recardsApp.swift`.
5. Создай структуру папок из раздела 14 (пустые директории под будущие этапы создавать не надо — только то, что нужно сейчас).
6. Замени `ContentView` на заглушку `TabView` с тремя вкладками из раздела 8, без содержимого.

**Результат этапа:** проект собирается, база данных создаётся, приложение запускается и показывает три пустые вкладки.

Работай последовательно, показывай, что делаешь. После завершения этапа остановись и покажи результат — следующие этапы запускать не надо.

Важно: перед написанием любого кода, работающего с `swift-fsrs`, свериться с README пакета. Перед использованием API iOS 26 (Liquid Glass, `.glassEffect()`, `.tabBarMinimizeBehavior`) — убедиться в точных сигнатурах, а не писать по памяти.
